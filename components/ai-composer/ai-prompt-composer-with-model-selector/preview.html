AI Prompt Composer with Model Selector

这是一个 React + TypeScript 组件，需要在 React / Next.js 项目里运行，见同目录 component.tsx。

一眼看清

  • 输入框：Plan / Build / Automate，输入 @ 出上下文菜单
  • 左下：+ Add files、模式切换；右下：模型选择、录音、发送
  • 模型菜单：收藏、搜索、Effort 子菜单、Auto 开关
  • 深色 / 浅色主题切换，底部有升级横幅和演示导览

怎么跑起来

放到 components/ui/ai-prompt-composer-with-model-selector.tsx
import AIComposer from "@/components/ui/ai-prompt-composer-with-model-selector";
<AIComposer onSubmit={(s) => console.log(s)} />
