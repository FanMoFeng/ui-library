Claude Model Selector / Effort Slider

这是一个 Web Component + React 封装，不依赖 Tailwind，见同目录 component.tsx 和 demo.tsx。

一眼看清

  • 触发按钮显示当前档位，如 Low
  • 弹出的面板：Effort + 当前档位、帮助气泡、Faster → Smarter、滑杆
  • 六档：Low / Medium / High / Extra / Max / Ultracode，最后一档有紫色像素流光

怎么跑起来

<claude-model-selector value="0" open></claude-model-selector>
或 React：<ClaudeModelSelector value={0} open />
